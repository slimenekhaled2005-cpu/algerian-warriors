# Algerian Warriors Website

Official landing page for Algerian Warriors.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy on Vercel

1. Upload this project to GitHub.
2. Go to Vercel.
3. Click New Project.
4. Import the GitHub repository.
5. Deploy.
6. Go to Project Settings > Domains.
7. Add `algerianwarriors.com`.
